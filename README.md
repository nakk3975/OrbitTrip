# OrbitTrip 0.2 — fixed-moment travel planner

외부 여행 API 없이 동작하는 비공개 인터랙티브 프로토타입. Node 22+ / HTML / CSS / JavaScript ES modules.

## 실행

```sh
npm ci
npm start
# http://localhost:3000
npm test
npm run build
```

## 사용자 흐름

1. 다크모드의 큰 지구로 시작합니다. 드래그·방향키로 회전하고, 세계지도 버튼으로 넓은 지도/국가 카드 탐색으로 전환합니다. 확대·축소·초기화·국가 검색도 지원합니다.
2. 국가 선택 후 상세 계획 화면으로 이동합니다. 날짜별 도시, 활동 시작·종료 시각, 여행 속도를 정합니다.
3. 고정 방문/예약과 기차 이동을 추가합니다. 하루 전체, 오전/오후 시간 예시 또는 직접 입력을 지원합니다.
4. 예약 시간을 그대로 유지하며 이동과 대기 시간을 고려해 남는 시간을 채웁니다. 빈 시간이 남으면 휴식 또는 수동 추가에 사용할 수 있습니다.
5. 결과를 직접 수정·삭제·추가하고 JSON으로 내보낼 수 있습니다. 설정 변경 때 기존 결과를 즉시 지우지 않고 재추천 필요 상태를 표시합니다. 재추천은 고정 일정을 유지하며 자유 일정 편집은 대체합니다.

### 도쿄 예시

고정 일정이 없는 4일 이상 도쿄 여행에서 `도쿄 4가지 방문 예시 추가` 버튼:
- 1일차 디즈니랜드: 하루 전체, 이동 포함, 다른 추천 없음.
- 2일차 가스카베: 10:00–12:00 고정. 이동 여유를 반영한 활동 시작 추천.
- 4일차 오다이바: 13:00–15:00 고정.
- 4일차 팀랩 플래닛: 16:00–18:00 고정.

예약 전 15분, 기차 출발 전 30분, 도착 후 20분 여유. 중심역을 첫 출발점으로 가정합니다. 활동시간 추천은 고정 일정과 이동 추정치를 사용하며 실제 개장 시간을 뜻하지 않습니다. 야간을 넘기는 일정은 미지원. 겹치는 예약·부족한 이동·활동시간 이탈은 생성 전에 알려줍니다. 수동 편집 후 충돌은 결과에 경고합니다.

## 지도

Natural Earth 공용 지형 데이터를 빌드 결과에 포함했습니다. 출처는 `public/MAP-LICENSE.txt`.
- 세계지도: 날짜변경선에서 분할한 폴리곤.
- 지구: 평면 해안선 마스크를 가시 반구의 각 픽셀에 역투영. 숨은 꼭짓점을 직선으로 연결하지 않아 회전 시 찢어진 삼각형이 생기지 않습니다.
- 360° 회전 수학 테스트와 6개 방향의 실제 브라우저 캡처 검증.
- 첨부 참고 영상의 넓은 지도 중심 탐색 방식을 참고했으며 영상 화면·에셋·브랜드를 복사하지 않았습니다.

## 데이터 및 저장 범위

일본(도쿄·교토·오사카), 한국(서울·부산), 프랑스(파리), 이탈리아(로마). 장소 좌표·소요시간은 계획용 근삿값입니다. 식사는 식당가 추천이며 실시간 평점·영업시간·예약·교통편·요금은 조회하지 않습니다. 경로도는 직선 연결도입니다. 내장 추천 장소가 소진되면 직접 장소와 좌표를 추가할 수 있습니다.

localStorage에 국가별 초안을 보관합니다. 기존 v1 저장을 읽고 v2로 옮기되 v1 원본 키를 삭제하지 않습니다. 같은 브라우저/사이트에서만 복원됩니다. Render 서버에 DATABASE_URL을 설정하면 Neon에 국가별 일정을 저장·불러올 수 있습니다. 브라우저 자동 저장과 서버 수동 저장은 별개입니다. 서버 불러오기는 현재 브라우저 일정을 대체하기 전 확인을 받습니다.

## 배포

`npm run build`로 정적 배포용 dist를 만듭니다. 기존 비공개 호스팅의 전용 설정은 이 저장소에 포함하지 않습니다.

`render.yaml` 및 `deploy/render.yaml`: Render 배포 설정. 프로덕션은 APP_USER/APP_PASSWORD가 없으면 시작하지 않습니다. HTTPS 환경에서 HTTP Basic 인증으로 보호하며 `/health`만 비인증 응답합니다.

`deploy/neon-schema.sql`: Neon 일정 저장 스키마. 런타임은 SELECT/INSERT/UPDATE만 가진 별도 역할을 사용하며 RLS로 소유자를 구분합니다. DATABASE_URL은 Render 비밀 환경변수에만 넣습니다. 서버 저장은 revision 조건으로 다른 탭의 변경을 보호합니다.

## 검증 (2026-09-21)

- Node 테스트 18개: 날짜, 도시 연결, 기차 유지, 고정 방문/하루 전체, 활동시간 추천, 이동 충돌, 예약 재생성 보존, 중복 추천 방지, 구면 투영 왕복.
- 실제 Chromium: 큰 지구/세계지도 전환·회전·확대, 국가 선택 후 단계 전환, 사용자 예시 4개, 직접 방문 추가, 예약 수정 및 재추천, 충돌 차단, 새로고침 복원, 국가별 초안.
- 1440px PC 및 390px 모바일에서 화면 확인. 모바일 활동시간 필드와 날짜 탭의 가로 넘침 수정.
- 브라우저 검증 중 JS 오류 0개, 외부 네트워크 요청 0개.

브라우저 테스트는 Playwright/Chromium을 별도 설치한 개발 환경에서 `npm run test:browser`로 실행합니다. `CHROMIUM_PATH`로 설치된 실행파일을 지정할 수 있습니다. 테스트는 서버를 직접 시작·종료하고 캡처는 `SHOT_DIR` 또는 `/tmp/orbittrip-frames`에 저장합니다.

### 이동수단 비교
자동차·대중교통·도보 선택을 추천, 활동시간 제안, 빈 시간, 도착 가능 여부에 반영합니다. 결과에서 변경하면 예약과 편집한 방문 시각을 유지하며 충돌을 다시 계산합니다. 추천 재생성은 명시적으로 실행합니다. `routeEstimate`가 오프라인 교통 추정의 경계이며 향후 지도/교통 제공자로 교체할 수 있습니다. 현재 구간 표시는 이동 흐름이며 실제 도로, 노선, 환승 또는 통행 가능 여부를 계산하지 않습니다. 외부 API 및 인증키를 사용하지 않습니다.

## Render · Neon 연결

Node 22 이상. Render 환경변수: `NODE_ENV=production`, `APP_USER`, `APP_PASSWORD`, `DATABASE_URL`(Neon pooled URL, TLS 인증서 검증). `/health`를 제외한 화면·파일·저장 API는 HTTP Basic 인증으로 보호됩니다. 공유 계정 1개를 사용하는 개인 프로토타입이며 회원가입 서비스는 아닙니다.

Neon 프로젝트: `OrbitTrip` (`late-mud-28122960`), Singapore. 런타임 역할은 `orbittrip_app`. `/api/storage`는 연결 설정 유무, `/api/drafts/:country` GET/PUT는 국가별 저장/조회를 제공합니다. DB 비밀번호는 Git에 포함하지 않습니다. 실제 Render 배포는 작업 공간 확인 후 진행합니다.

DB 통합 검증: `node --env-file=.env.local tests/storage.integration.mjs`. 실행 환경에서 DB 호스트로 네트워크 접근이 가능해야 합니다.
